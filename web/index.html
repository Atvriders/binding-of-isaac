Isaac Cabinet
Graphics acceleration is off, so the game will look wrong. Ruffle has fallen back to software rendering, which cannot draw this game's floor, wall and rock textures — you will see flat colours and invisible objects you still collide with. Turn on hardware acceleration in your browser (Edge: Settings → System → "Use graphics acceleration when available"), then restart it.

    Controller

    Left stick or d-pad moves. Right stick or the face buttons shoot. Shoulders and triggers are bomb, item and pill. Start pauses.

    Item browser

    Ctrl + K opens the item list, or use the Items button. Typing there never reaches the game. Auto-ID watches the screen and names items as you pick them up.

    Saves

    Progress is stored by your browser, not by the server, so restarting the container never loses it — but clearing site data will. Use Export save for a real backup.
